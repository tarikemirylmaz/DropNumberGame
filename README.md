# Drop Number Game

A Java-based number game developed using custom linked data structures.

## About the Project

Drop Number Game is a Java project that implements a number-based game using linked data structures.

The project was developed to practice object-oriented programming and data structure concepts in Java.

## Technologies Used

- Java
- NetBeans
- Object-Oriented Programming (OOP)
- Linked Data Structures

## Project Structure

- `GameMain.java` - Starts the application
- `DropNumberGame.java` - Contains the main game logic
- `Node.java` - Represents the node structure
- `MoveNode.java` - Represents move-related node data
- `MultiLinkedList.java` - Implements the linked data structure used by the game

## Concepts Practiced

- Classes and Objects
- Linked Lists
- Nodes
- Object-Oriented Programming
- Game Logic
- Data Structure Implementation
